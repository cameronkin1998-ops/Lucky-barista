# Style References — the house standard

Drop the examples of the content you want to make here: screenshots, screen recordings, or links in the index below. Each one gets an ID, and briefs refer to it ("shoot like REF-03").

## How to add one

1. Save the file as `REF-XX-short-name.mp4` / `.png` (or just paste the link into the index).
2. Add a row to the index and fill in **what to copy**. That column is what turns an example into a standard.
3. If 3 or more references share a trait, promote that trait into [`../03-ugc-style-standard.md`](../03-ugc-style-standard.md).

## What to look at in each reference

- **Hook:** what happens in second 0–1? Text, motion, a face, sound?
- **Pacing:** how many cuts in the first 5 seconds?
- **Framing:** top-down, eye level, POV hands, talking head?
- **Light and setting:** time of day, how tidy or messy, color tone?
- **Text style:** native font, captions, where the price appears?
- **Audio:** voiceover, trending sound, ASMR, music volume?
- **CTA:** how does it ask for the click, and where?
- **Proof:** does it show results, comments or reactions?
