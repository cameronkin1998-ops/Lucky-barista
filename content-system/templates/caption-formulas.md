# Caption Formulas (one product, one keyword)

**TikTok:**
```
<hook line>
<what it does, in one line> · $<price>
Tap the cart 🛒 or DM me <KEYWORD> for the link
#coffeetok #homebarista #giftideas #<product tag>
```

**Instagram:**
```
<hook line>
<1–2 lines: the payoff + one specific detail>
💬 Comment <KEYWORD> and I'll DM you the link
Save this for gift season 🎁
#homebarista #coffeecorner #latteart #giftsforcoffeelovers
```

**Facebook:**
```
<hook line> ☕
<2–3 lines: what it does, who it's for, the gift angle>
$<price> · ships in 2–3 days
👉 Comment <KEYWORD> and we'll message you the link
```

**Examples**
- FOAM: "Stop paying $6.50 for this ☕ The NanoFoamer V2 makes café microfoam in about 20 seconds, no steam wand. $59.95. 💬 Comment FOAM and I'll DM you the link"
- SHOT: "Your espresso is channeling and you can't see it 👀 The UpShot mirror shows you the bottom of your shot. $34.95. 💬 Comment SHOT"
